### 📖 Description
This repository contains academic projects and exercises from my **second semester** at Estácio University. The focus of this period was deepening logic with **C/C++** and an introduction to **hardware interaction**.

### 📂 Featured Projects
*   **Game Development:** Basic implementation of a "Battleship" (Batalha Naval) game in C.
*   **Algorithms:** Advanced search and decision-making structures (Busca Condicional, DoWhile).
*   **Graphics:** 3D logic concepts like the `Cuborotativo.c`.

### 🛠️ Key Learnings
*   Memory management and pointers in C.
*   Compilation workflows and source code organization.
